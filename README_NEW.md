# MFI Controller Support for Geometry Dash iOS

A Geode mod that adds comprehensive MFI (Made for iPhone) controller support to Geometry Dash on iOS, bringing full feature parity with the PC version.

## ✨ Features

- **Full controller input support** for all game modes (classic, platformer)
- **Complete menu navigation** with controller across all screens
- **Practice mode controls** including checkpoint management  
- **Always-visible button prompts** (PC-style controller UI)
- **Platformer mode** left stick / D-pad movement
- **Multiple jump inputs** (A button, RT, LT triggers)
- **Comprehensive pause menu** controls

See [CONTROLLER_FEATURES.md](CONTROLLER_FEATURES.md) for the complete list of all controller mappings.

## 🎮 Supported Controllers

Any MFi-certified controller, including:
- Xbox Wireless Controller
- PlayStation DualShock 4 / DualSense
- SteelSeries Nimbus+
- Backbone One
- Razer Kishi
- Other MFi-certified gamepads

## 📦 Installation

1. Install [Geode](https://geode-sdk.org/) on your iOS device
2. Download the latest release from the Geode mod index
3. Enable the mod in Geode
4. Connect your controller and play!

## 🚧 Work in Progress

This mod is under active development. Editor/cursor support is not yet implemented.

## 🛠️ Building from Source

Requires the Geode SDK for iOS:
```bash
geode build
```
